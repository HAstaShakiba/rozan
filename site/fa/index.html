روزنRozan

یک ناچ برای بالای دسکتاپ لینوکس، با الهام از NotchNook در مک. آهنگی که پخش می‌شود، جلسه‌ی بعدی و کاری که Claude Code انجام می‌دهد را نشان می‌دهد و با بردن ماوس رویش، به یک مرکز کنترل کوچک باز می‌شود.

فعالیت‌های زنده، یکی‌یکی

وقتی بسته است، ناچ یک قرص سیاه کوچک روی نوار بالاست. مهم‌ترین اتفاق همین لحظه را نشان می‌دهد و وقتی پنجره‌ای تمام‌صفحه شود، کنار می‌رود.

  1. صدا و روشنایی به‌جای پنجره‌ی پیش‌فرض گنوم؛ وصل یا جدا شدن شارژر و کم شدن باتری؛ تمام شدن یک دانلود؛ رسیدن یک اعلان تازه.
  2. Claude Code وقتی منتظر تأیید شماست.
  3. تایمر تمرکز و استراحت وقتی در حال اجراست.
  4. جلسه‌ای که تا ۱۰ دقیقه‌ی دیگر شروع می‌شود.
  5. دانلودی که در ~/Downloads در جریان است.
  6. Claude Code وقتی روی یک قدم کار می‌کند، بعد موسیقی با کاور و اکولایزر، و در آخر ساعت.

اعلان‌ها

  • همه‌ی اعلان‌های گنوم، از جدید به قدیم، با نام برنامه، عنوان، متن و زمان.
  • با کلیک بازش کنید، با × ببندیدش یا با Clear all همه را پاک کنید؛ از گنوم هم پاک می‌شوند.
  • اعلان تازه در ناچ بسته هم چشمک می‌زند، مگر وقتی «مزاحم نشوید» روشن است.

Nook

  • پخش‌کننده‌ی کوچک با آیکون برنامه روی کاور.
  • کاشی پردازنده و باتری با نمودار تاریخچه (روی دسکتاپ، حافظه).
  • تایمر تمرکز و استراحت: خط‌کش را بکشید یا اسکرول کنید؛ در پایان صدا و اعلان می‌دهد.
  • کارها: کلیک برای تیک زدن، کلیک راست برای حذف.

موسیقی

  • با هر پخش‌کننده‌ی MPRIS کار می‌کند: Spotify، فایرفاکس، کرومیوم، VLC و بقیه.
  • کاور، نام آهنگ و خواننده، با نوار پیشرفتی که می‌شود کشید و جلو و عقب رفت.
  • قبلی، پخش/توقف و بعدی؛ اسکرول افقی هم آهنگ را عوض می‌کند.

تقویم

  • رویدادهای باقی‌مانده‌ی امروز و رویدادهای فردا، از سرویس تقویم گنوم.
  • تقویم‌های GNOME Online Accounts و Evolution را هم شامل می‌شود.
  • رویدادی که در جریان است با Now مشخص می‌شود.

سینی فایل

  • قفسه‌ای برای فایل‌هایی که قرار است به‌زودی استفاده کنید.
  • فایل‌ها را در Files کپی کنید و Paste را بزنید (گنوم ۴۲ کشیدن و رها کردن از برنامه‌های ویلند را نمی‌گیرد).
  • باز کردن، کپی، نمایش در Files یا حذف هر فایل.

پرامپتر

  • تله‌پرامپتر درست زیر وبکم.
  • متن‌های ساده‌ی .txt، شمارش معکوس ۳ ثانیه‌ای و تنظیم سرعت و اندازه‌ی متن.
  • هنگام ضبط، با قفل باز نگهش دارید.

ایجنت‌ها

  • همه‌ی جلسه‌های Claude Code را دنبال کنید: درخواست، فهرست کارها و دستوری که الان اجرا می‌شود.
  • درخواست‌های مجوز را از خود ناچ تأیید یا رد کنید، یا به ترمینال بروید.
  • برای هر جلسه یک برچسب؛ ترمینال‌های بسته‌شده خودشان حذف می‌شوند.

کلاسیک یا شیشه‌ای

برای عوض کردن ظاهر، روی نوار زبانه‌ها کلیک راست کنید.

نصب

روزن روی GNOME Shell 42 (اوبونتو ۲۲.۰۴) در نشست ویلند کار می‌کند. گنوم روی ویلند افزونه‌های جدید را فقط موقع ورود پیدا می‌کند، پس بعد از نصب یک بار خارج شوید و دوباره وارد شوید.

از فایل zip نسخه

فایل rozan-…zip را از آخرین نسخه بگیرید، بعد:

mkdir -p ~/.local/share/gnome-shell/extensions/rozan@hastashakiba.github.io
unzip rozan-*.zip -d ~/.local/share/gnome-shell/extensions/rozan@hastashakiba.github.io
# log out and back in, then:
gnome-extensions enable rozan@hastashakiba.github.io

از سورس

خود ریپو همان افزونه است؛ لینکش کنید و با git pull به‌روز کنید:

git clone https://github.com/HAstaShakiba/rozan.git
ln -s "$PWD/rozan" ~/.local/share/gnome-shell/extensions/rozan@hastashakiba.github.io
# log out and back in, then:
gnome-extensions enable rozan@hastashakiba.github.io

اتصال Claude Code (اختیاری)

بخش ایجنت‌ها از یک hook داده می‌گیرد. hooks/notch-hook.py را برای رویدادهای جلسه، درخواست، ابزار، مجوز، کار و توقف به ~/.claude/settings.json اضافه کنید. متن کامل در README هست. هر درخواست مجوز تا ۶۰ ثانیه منتظر جواب در ناچ می‌ماند و بعد به ترمینال برمی‌گردد.

پرسش‌ها

NotchNook برای لینوکس هست؟

خود NotchNook فقط برای مک است. روزن یک افزونه‌ی رایگان و متن‌باز گنوم با همین ایده است: ناچی بالای وسط صفحه با موسیقی، فعالیت‌های زنده و ابزارهای سریع.

صفحه‌ی من ناچ ندارد. مشکلی نیست؟

نه. روزن ناچ خودش را روی وسط نوار بالا می‌کشد، پس روی هر نمایشگری کار می‌کند.

کدام نسخه‌های گنوم پشتیبانی می‌شوند؟

GNOME Shell 42، همان که با اوبونتو ۲۲.۰۴ می‌آید، در نشست ویلند. نسخه‌های جدیدتر گنوم قالب افزونه‌ی دیگری دارند و هنوز پشتیبانی نمی‌شوند.

منوی تاریخ را می‌پوشاند؟

بله. ناچ روی وسط نوار بالا، شامل ساعت و منوی تاریخ، قرار می‌گیرد. ناچ بسته خودش ساعت را نشان می‌دهد.

«روزن» یعنی چه؟

روزن دریچه‌ی کوچکی بالای دیوار است که نور از آن به خانه می‌آید.
